# Ruta Nido

Estrategia TIC-TAC-TEP de la **Fase 3** (Recursos digitales para la Educación · Maestría en Educación Inclusiva e Intercultural · Universidad El Bosque).

## Qué hay en este repositorio

| Archivo | Qué es |
| --- | --- |
| `index.html` | Presentación interactiva de 14 pantallas guiada por Pío (qué pasa en Jardín, qué son TIC-TAC-TEP, la ruta, los cuatro momentos, DUA, herramientas, juego y dónde se aplica). |
| `recursos/index.html` | Kit de recursos: todos los espacios reales, con instrucciones para crear el Padlet y la carpeta de Drive. |
| `recursos/agenda.html` | Agenda visual del día (tablero «Ahora / Después», voz, reorganizar, imprimir). |
| `recursos/cuento.html` | Cuento narrado «El globo que se calma». |
| `recursos/libro-de-calma.html` | Cada niño crea su página con carita, estrategia, dibujo y voz; el libro se imprime. |
| `recursos/rincon-de-calma.html` | Rincón de calma digital para la tableta: caritas, globo, conteo, pelota y reloj de pausa. |
| `recursos/asamblea.html` | Votación del rincón y del pacto, semáforo y decisión semanal. |
| `recursos/docentes.html` | Protocolo común de 4 pasos, registro semanal imprimible y taller. |
| `recursos/familias.html` | Carta, agenda de la mañana para la nevera y guiones de mensajes de voz. |
| `recursos/estilo.css`, `recursos/comun.js` | Estilo y funciones compartidas (voz, tamaño de letra, contraste). |

## Publicar en GitHub Pages

1. Suba **todo**, incluida la carpeta `recursos` con sus archivos. En GitHub: *Add file → Upload files* y arrastre la carpeta completa.
2. **Settings → Pages →** *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
3. Enlaces: `https://germanvelandia.github.io/ruta-nido/` y `https://germanvelandia.github.io/ruta-nido/recursos/`.

## Enlaces de Padlet, Drive y Genially

Cuando el equipo los cree, edite `recursos/index.html` (lápiz ✏️), busque `const ENLACES` al final y pegue cada enlace entre las comillas.

Ninguna página pide, guarda ni envía datos. Pictogramas representados con emojis; en el aula se usan los de ARASAAC (Gobierno de Aragón, CC BY-NC-SA). El estudiante se identifica como «Estudiante A».
